# Arrow Game

A simple browser game where you aim with the left/right arrow keys and shoot with the space bar.

## How to Play

- Use **Left/Right Arrow Keys** to rotate your bow
- Press **Space** to shoot arrows
- Hit the red targets before they reach the bottom
- Game ends when a target reaches the bottom of the screen

## Run it locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then open:
```
http://localhost:8000
```

## Features

- Simple aim-and-shoot mechanics
- Score tracking
- Collision detection
- Smooth animations
